# C Strings

A collection of **C programs based on Strings and String Manipulation**.
This repository contains beginner-friendly problems designed to strengthen understanding of character arrays, strings, loops, conditions, and basic string operations.

## 📌 Topics Covered

* String input and output
* Finding string length
* Reversing a string
* Checking whether a string is a palindrome
* Character frequency
* Counting vowels and consonants
* Counting letters and digits
* Counting spaces
* Counting words in a sentence
* Uppercase and lowercase conversion
* Character ASCII values
* First and last character operations
* Middle character of a string
* String concatenation
* Reversing individual words
* Checking strings in reverse
* Removing first and last characters
* Checking whether a string is empty
* Working with words starting with vowels

## 🛠️ Language

The main purpose of this repository is to practice **C strings and character-array problems** and build a strong foundation in problem solving and programming logic.
